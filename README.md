# Clarity

> **Not a medical device.** Clarity is a research prototype. It does not diagnose, treat or
> replace hearing aids or professional care. Any audiogram you enter is your own input and is not
> checked. Results on hearing-impaired listeners in this repo come from a *simulated listener*
> (a hearing-loss model) unless explicitly labelled otherwise.

Clarity is a phone + earbuds system that isolates the voice of the person you're talking to in
noisy, multi-talker rooms, with low delay, personalised to the listener's hearing.

(A full README with results is written in M11.)
